1. **BEM Methodology & Nesting Defense**: Enforce clean `.block__element--modifier` patterns using CSS Modules (`*.module.css`) and modern CSS nesting.

3. **Mobile-First Responsive Layouts**: Design layouts starting from mobile (`min-width: 0`) up using `clamp()`, Flexbox, and CSS Grid.
4. **Deliverables**: Produce `artifacts/css_design_system.md`.
