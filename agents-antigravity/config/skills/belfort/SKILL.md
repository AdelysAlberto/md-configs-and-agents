## High-Conversion Landing Page Persuasion Framework

### Core Frameworks
- **AIDA**: Attention $\to$ Interest $\to$ Desire $\to$ Action.
- **BAB**: Before (pain state) $\to$ After (ideal state) $\to$ Bridge (the solution).
- **PAS**: Problem $\to$ Agitate (cost of inaction) $\to$ Solve (the product).
- **4Ps**: Picture (vision) $\to$ Promise (USP) $\to$ Proof (social/data) $\to$ Push (CTA).
- **FAB**: Feature (technical spec) $\to$ Advantage (how it works) $\to$ Benefit (tangible outcome).

### Landing Page Execution Blueprint (Section by Section)

| Section | Framework Synthesis | Required Copy Elements | UX/UI & Visual Direction |
| :--- | :--- | :--- | :--- |
| **A. Hero Section** | AIDA + BAB + PAS + 4Ps | • **Attention Headline**: High-impact benefit / primary pain hook.<br>• **Interest Subtitle**: Before vs After connection.<br>• **Agitation**: Consequences of inaction.<br>• **Promise**: Unbeatable USP.<br>• **Primary CTA**: High-urgency action text. | High-contrast CTA button above fold, clean typography, zero visual noise. |
| **B. Problem & Solution** | BAB + FAB | • "Before" pain scenario.<br>• "After" ideal resolved state.<br>• The Bridge product reveal.<br>• Feature-Advantage-Benefit list. | Visual comparison cards, benefit icons, strictly zero tech specs without benefits. |
| **C. Social Proof & Credibility** | 4Ps (Proof) | • Concrete numbers & metrics.<br>• Verified client testimonials.<br>• Trust logos / badges. | High-visibility trust grid, bold metric callouts, undeniable credibility anchors. |
| **D. Benefits & Differentiation** | FAB + AIDA | • Key value drivers list.<br>• USP vs market alternatives comparison. | 2-3 column layout, high scannability, strong visual contrast. |
| **E. Final Close & CTA** | AIDA + PAS | • Desire & urgency reinforcement.<br>• Risk reversal guarantee.<br>• Final CTA repeat. | Full-width high-contrast container, sticky CTA, minimal form fields. |
