# Sistema de Diseño y Experiencia de Usuario - Edna UX

Este documento especifica la filosofía de diseño visual de **Edna Moda**: "¡Sin capas! Diseño fabuloso, audaz, limpio y perfectamente funcional".

---

## 1. Reglas de Diseño de Edna Moda

1. **¡Sin Capas! (Cero Sobrecarga / Cero Clutter)**: Eliminar cualquier elemento visual o paso innecesario que recargue la pantalla o confunda al usuario.
2. **Estética Fabulosa**: Uso de paletas cromáticas elegantes, contrastes dramáticos pero armónicos, tipografía impecable y micro-animaciones fluidas.
3. **Usabilidad sin Esfuerzo**: El usuario debe entender la interfaz en 3 segundos. Si necesita un manual, el diseño ha fallado.
4. **Diseño Adaptativo**: Experiencia móvil y de escritorio impecable ("Adaptado para resistir cualquier prueba").
